# SCT_ML_03 - Cats vs Dogs Classification using SVM

## Objective
Implement a Support Vector Machine (SVM) model to classify images of cats and dogs.

## Dataset
Dogs vs Cats Dataset (Kaggle)

## Technologies Used
- Python
- NumPy
- OpenCV
- Matplotlib
- Scikit-Learn

## Machine Learning Algorithm
Support Vector Machine (SVM)

## Project Workflow
1. Data Collection
2. Image Preprocessing
3. Image Resizing
4. Grayscale Conversion
5. Feature Extraction
6. Model Training using SVM
7. Performance Evaluation

## Results
The SVM model was trained to classify cat and dog images and evaluated using accuracy score and confusion matrix.
